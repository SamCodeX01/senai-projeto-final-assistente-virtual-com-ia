# senai-projeto-final-assistente-virtual-com-ia
Projeto Final do curso de Inteligências Artificiais Generativas Aplicadas a Programação - ChatGPT: Desenvolver um Assistente Virtual Inteligente utilizando a API da OpenAI. O sistema deverá possuir um front-end desenvolvido em HTML, CSS e JavaScript, comunicando-se com uma API criada em Node.js responsável por acessar a OpenAI.
